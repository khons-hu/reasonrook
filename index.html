    About Khonsolve
    Khonsolve is an independent, open-source practice notebook. Exercises are original teaching examples, not copied LeetCode or HackerRank questions.
    Hints and explanations are authored content. Written work is self-reviewed. Code checks cover listed examples and edge cases, not every possible input.
    No account, trackers or paid model calls. Drafts are stored locally. Export a backup to keep them. JavaScript, TypeScript and Python run in disposable workers inside an isolated frame, with HTTP network access blocked and a code time limit. TypeScript is transpiled, not type-checked. C11 and C++17 compile locally using an experimental Clang 8 WebAssembly toolchain (about 60 MB on first use), with full-program output rather than automatic exercise checks. Go has saved drafts and an external playground link, without automatic code transfer.
